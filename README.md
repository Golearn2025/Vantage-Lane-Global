# Vantage Lane Global

Internal Ground Transportation Network CRM.

## App

```bash
cp .env.example .env.local
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js · TypeScript · Tailwind · shadcn-style UI · TanStack Query/Table · Supabase Auth + RLS

## Milestone 1 scope

Login → Organizations → Quick Add → Organization Profile → Contacts / Bases / Coverage → Outreach → Relationship lifecycle.

Realtime, Network map, Jobs, pricing, billing are out of scope for M1.
