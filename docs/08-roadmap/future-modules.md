# Future modules

Designed for, not built now.

| Module | Depends on staying generic now |
|---|---|
| Jobs / Requests | Coverage, eligibility, contacts, rate cards |
| Auto-quote | Structured GT rate rules |
| RFQ / assignment | Communications + offerings |
| Private Aviation | Organization + Offering + Location (airports already first-class) |
| Security | Same core; different capability pack |
| Hospitality | Same core; different pricing pack (not per-km) |
| Concierge | Same core |
| Buyer portal | Organization as buyer, not a new user type |
| Quality / performance | Activity + job outcomes |
| Billing | Separate; do not pollute offerings |

Rule: a future vertical adds a capability pack and catalog rows. It does not fork Organization.
