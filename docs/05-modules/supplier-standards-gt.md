# Ground Transportation — supplier standards (initial)

Configurable policy content for ADR-014. Levels: **REQUIRED** | **RECOMMENDED** | **OPTIONAL**.

Exact required-vs-recommended assignment per market is **OPEN** (legislation differs). Below is the initial VL intent for the premium GT network.

Default vehicle year parameter: **2023** (policy data, not code constant).

## Company / compliance

| Standard | Suggested level |
|---|---|
| Legally operating company | REQUIRED |
| Required local operator / licensing documentation where applicable | REQUIRED |
| Valid commercial / private hire insurance where applicable | REQUIRED |
| Required documents valid and not expired | REQUIRED |
| Operational contact details | REQUIRED |
| WhatsApp contact where available | RECOMMENDED |
| Acceptance of Vantage Lane Supplier Standards | REQUIRED |

## Vehicles

| Standard | Suggested level |
|---|---|
| Default minimum year (policy default 2023) | REQUIRED |
| Vehicle must match booked category | REQUIRED |
| Premium clean interior and exterior | REQUIRED |
| No category downgrade without approval | REQUIRED |
| Real fleet / vehicle information and images | REQUIRED |
| Passenger and luggage capacity declared | REQUIRED |

## Drivers

| Standard | Suggested level |
|---|---|
| Legally licensed where required | REQUIRED |
| Professional chauffeur presentation | REQUIRED |
| Formal / business attire appropriate for premium service | REQUIRED |
| Sufficient English for operational / passenger communication | REQUIRED |
| Punctuality | REQUIRED |
| Professional and discreet conduct | REQUIRED |
| No smoking in vehicle | REQUIRED |

## Service

| Standard | Suggested level |
|---|---|
| Premium bottled water | RECOMMENDED or REQUIRED — OPEN |
| Clean vehicle before pickup | REQUIRED |
| Flight monitoring where required | REQUIRED when applicable |
| Meet & greet where required | REQUIRED when applicable |
| Proactive delay / problem communication | REQUIRED |
| Driver / vehicle confirmation before service | REQUIRED |
| Provide driver name, phone, vehicle model and registration before pickup | REQUIRED |

## Operations

| Standard | Suggested level |
|---|---|
| Request acceptance / rejection expectations | REQUIRED (SLA values OPEN) |
| Immediate notification if service can no longer be fulfilled | REQUIRED |
| No unauthorized subcontracting to an unapproved provider | REQUIRED |
| Maintain reasonably accurate operational availability | REQUIRED |

## Eligibility note

Eligibility should eventually evaluate REQUIRED items (and document expiry). RECOMMENDED/OPTIONAL inform scorecards and reviews, not necessarily hard gates.
